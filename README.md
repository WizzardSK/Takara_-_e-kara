# Takara_-_e-kara

Thumbnails for Takara e-kara software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `ekara_japan`, `ekara_japan_a`, `ekara_japan_bh`, `ekara_japan_d`, `ekara_japan_en`, `ekara_japan_g`, `ekara_japan_gk`, `ekara_japan_kd`, `ekara_japan_m`, `ekara_japan_p`, `ekara_japan_packin`, `ekara_japan_s`, `ekara_japan_sp`, `ekara_japan_web`, `ekara_pal`, `ekara_us` software lists have them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
